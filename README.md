An e-commerce marketplace where independent sellers list and manage their products.

- **Product moderation with versioned revisions**: the approved version stays live while changes are reviewed
- Seller subscription plans and enforcement

- Secure document handling with signed uploads and downloads
- Redesigned public website (pricing, solutions, help) with an accessible, responsive layout
- Fully multilingual UI: FR / EN / AR

`Monorepo` `TypeScript` `Security` `i18n` `Responsive UI`

### 📊 Accounting & Financial Services Web App
